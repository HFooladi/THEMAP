# Research notebooks

Ongoing work that post-dates the published paper — exploration, analysis, and figures made
for talks. **Nothing here is part of the paper's results, and nothing here carries a
reproduction guarantee.** These notebooks track the library as it changes and may break.

Looking to reproduce the paper? It is in [`../paper/`](../paper/).

| Notebook | What it does | Data it needs |
|---|---|---|
| `fsmol_benchmark_explorer.ipynb` | Guided tour of the FS-Mol benchmark itself — fold sizes, class balance, protein-family shift, molecule overlap between folds, chemical diversity, and FS-Mol's own published baselines | `benchmarking_datasets/fsmol_datasets/` (separate [FigShare download](https://figshare.com/ndownloader/files/31345321), *not* the Zenodo archive) |
| `metalearning_reproduction.ipynb` | Distance-guided meta-learning: ProtoNet and MAML over distance-selected sources, close-vs-far transfer contrast, and distance-vs-random source selection | `datasets/` plus a distance file generated by `quick_distance` |
| `figure_for_presentation.ipynb` | The THEMAP hero figure — UMAP landscape of 5,095 FS-Mol task centroids with OTDD nearest-source arrows | `datasets/fsmol_hardness/` (the Zenodo archive) |

`fsmol_benchmark_explorer.ipynb` caches its scans under `cache/` (gitignored) so only the
first run is slow.
